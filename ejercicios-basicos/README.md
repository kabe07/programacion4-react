# Trabajo práctico de React

Alumno: Martín Fernandez

Contiene siete ejercicios:
1. Tarjetas de productos con props.
2. Contador con límites.
3. Mostrar y ocultar una respuesta.
4. Conversor de temperatura.
5. Lista de compras.
6. Buscador de lenguajes.
7. Productos con TypeScript y prop opcional.

## Requisitos

Node.js y npm instalados.

## Ejecutar el proyecto

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
npm install
npm run dev
```

Abrir en el navegador la dirección indicada en la terminal.

## Organización

Los ejercicios están en src/ejercicios.
App.jsx muestra los siete ejercicios en una misma página.
